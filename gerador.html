MontaHorário — Gerador de dados por curso

Cole abaixo o HTML do relatório "Turmas Abertas" da UTFPR (o mesmo conteúdo que fica em codigofonte.txt). O script extrai as disciplinas e gera um arquivo data/<slug>.json — o formato que o site carrega sob demanda quando alguém escolhe esse curso no seletor. Cada curso é gerado separadamente, um relatório de cada vez.

⚠️ Não consegui carregar as sedes/cursos já existentes (data/sedes.json / data/<sede>/manifest.json) para sugerir nos campos abaixo — isso é normal se você abriu este arquivo direto do disco (file://), já que o navegador bloqueia esse tipo de busca nesse caso. Sirva a pasta com um servidor local (ex: npx serve, extensão "Live Server") ou abra pelo GitHub Pages para ativar as sugestões. Os campos continuam funcionando normalmente por digitação.

Vira a pasta data/<sede>/. Escolha uma sede já existente na lista ou digite uma nova — para adicionar uma sede de fato, crie a pasta e inclua a entrada correspondente em data/sedes.json.
Vira data/<sede>/<slug>.json. Mostra os cursos já cadastrados na sede acima — escolher um existente vai sobrescrever aquele curso; use só letras minúsculas, números e hífen para um novo.
É o texto que aparece no dropdown de cursos do site. Preenchido automaticamente se você escolher um curso já existente.
